# Prosepago Connect — versiones

Enlace entre los puntos de venta (Soft Restaurant; próximamente Microsip) y la terminal Prosepago.

Este repositorio solo publica las versiones instalables en **Releases**. Cada versión trae:

- `ProsepagoConnect.exe` — el programa.
- `version.json` — manifiesto firmado por Streamlite Technologies (RSA-SHA256). Prosepago Connect solo instala una versión si la firma es válida y la huella SHA-256 del `.exe` coincide.

Para instalar o actualizar, usa el botón **Buscar actualización** dentro de Prosepago Connect.
